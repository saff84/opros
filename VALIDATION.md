# Проверка автономной версии

Проверено при подготовке 14.10.2026:

- Production-сборка обычного Next.js 16.3.4 с webpack и проверкой TypeScript.
- Запуск собранного `standalone/server.js` на Node.js 24.19.0.
- Страница опроса и локальный WOFF2-шрифт отдавались с HTTP 200.
- `/api/health` возвращал HTTP 200 и создавал реальную SQLite-базу.
- Создание сессии, сохранение и восстановление черновика без cookie.
- Отправка заполненной анкеты и защита от повторной отправки.
- Проверки обязательных ответов и отклонение запроса с другого origin.
- Отказ в доступе к результатам без пароля; вход администратора и чтение ответов.
- Сохранение завершённой анкеты после перезапуска standalone-процесса.
- Создание согласованной копии через SQLite backup API.
- Восстановление копии в другой файл SQLite; проверка количества записей.
- Импорт JSON в новую базу и повторный импорт без дублирования записей.
- Синтаксис shell-скрипта установки; чтение обоих Compose-файлов как YAML.
- Lockfile npm содержит закреплённые версии и адреса публичного registry.npmjs.org.

Тесты использовали отдельную временную базу и вымышленные ответы. Тестовые анкеты, рабочие пароли и собранные ответы пользователей в архив не включены.

Ограничения проверки:

- Docker Engine в среде подготовки отсутствовал: Dockerfile не собирался Docker-движком, Compose-сервисы не запускались.
- Выпуск HTTPS-сертификата Caddy, правила firewall, DNS и доступность из российских сетей проверяются после установки на ваш сервер.
- Визуальная проверка автономной версии в браузере и нагрузочное тестирование не выполнялись. Интерфейс перенесён из опубликованного опроса; отдельно проверены его сборка и серверный сценарий.

## Docker после обновления 15.10.2026

Проверка `npm run test:docker` завершилась успешно на Docker Engine 29.2.1 и Compose 5.0.2:

- Собран Linux-образ: Next.js 16.3.4, TypeScript, Node.js 24.22.0.
- Проверены основная Compose-конфигурация и объединение с HTTPS-файлом.
- Контейнер прошёл healthcheck и работает с UID 1000. Статика и необходимые скрипты присутствуют.
- HTTP-сценарии прошли: редактор вопросов, версии, архив, ноль/несколько активных опросов, ветвление, картинки, вход/выход и смена пароля.
- После перезапуска сохранены ответы, картинки и изменённый пароль; первоначальный пароль отклоняется.
- В контейнере проверены JSON-импорт с картинкой и ветвлением, резервная копия и восстановление SQLite; данные и подпись участника сохранены.
- Отдельные тестовые проект, образ и том удалены после завершения. Рабочая база и `.env` не использовались.

Реальный выпуск TLS-сертификата, визуальная проверка браузера и нагрузочное тестирование этим тестом не выполняются.

После добавления минимума и максимума для множественного выбора успешно прошли 49 автоматических тестов. Дополнительно проверены диапазон и точное количество ответов, незавершённые черновики, необязательные и исключающие варианты, серверная проверка, сохранение лимитов и перенос через JSON, подсказки и счётчик выбранного.

После изменения поведения исключающих вариантов добавлена проверка блокировки всех невыбранных ответов при максимуме и разблокировки после снятия выбора, включая максимум 1. Проверены компактные раскрывающиеся настройки редактора и пояснение для первого вопроса. Всего 50 тестов. Визуальная проверка в браузере не выполнялась.

Приветственный блок: добавлена проверка сохранения настроек без смены версии вопросов, публичного чтения, проверки форматов и лимитов, запрета неизвестных файлов, доступа к картинкам активных/закрытых опросов, переноса картинок и настроек через JSON и экранирования текста. Всего 51 тест. Docker-сценарий дополнен проверкой сохранения заголовка и изображения блока после перезапуска и восстановления SQLite.
