# Проверка автономной версии

Проверено при подготовке 14.10.2026:

- Production-сборка обычного Next.js 16.3.4 с webpack и проверкой TypeScript.
- Запуск собранного `standalone/server.js` на Node.js 24.19.0.
- Страница опроса и локальный WOFF2-шрифт отдавались с HTTP 200.
- `/api/health` возвращал HTTP 200 и создавал реальную SQLite-базу.
- Создание сессии, сохранение и восстановление черновика без cookie.
- Отправка заполненной анкеты и защита от повторной отправки.
- Проверки обязательных ответов и отклонение запроса с другого origin.
- Отказ в доступе к результатам без пароля; вход администратора и чтение ответов.
- Сохранение завершённой анкеты после перезапуска standalone-процесса.
- Создание согласованной копии через SQLite backup API.
- Восстановление копии в другой файл SQLite; проверка количества записей.
- Импорт JSON в новую базу и повторный импорт без дублирования записей.
- Синтаксис shell-скрипта установки; чтение обоих Compose-файлов как YAML.
- Lockfile npm содержит закреплённые версии и адреса публичного registry.npmjs.org.

Тесты использовали отдельную временную базу и вымышленные ответы. Тестовые анкеты, рабочие пароли и собранные ответы пользователей в архив не включены.

Ограничения проверки:

- Docker Engine в среде подготовки отсутствовал: Dockerfile не собирался Docker-движком, Compose-сервисы не запускались.
- Выпуск HTTPS-сертификата Caddy, правила firewall, DNS и доступность из российских сетей проверяются после установки на ваш сервер.
- Визуальная проверка автономной версии в браузере и нагрузочное тестирование не выполнялись. Интерфейс перенесён из опубликованного опроса; отдельно проверены его сборка и серверный сценарий.
