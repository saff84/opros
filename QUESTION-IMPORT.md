# Загрузка вопросов из файла

В кабинете на странице списка опросов нажмите «Скачать шаблон JSON», заполните файл в кодировке UTF-8, затем нажмите «Загрузить вопросы». Импорт доступен администратору и редактору. После проверки откроется редактор нового опроса. Настройте оформление, загрузите картинки и нажмите «Сохранить изменения». До сохранения новый опрос не записывается в базу. Он создаётся как черновик.

Файл содержит `format: "sanext-questions"`, `version: 1`, `title` (название до 160 символов) и массив `questions` от 1 до 60 вопросов. Максимальный размер файла — 90 000 байт. Это шаблон вопросов и вариантов выбора; заполненные анкеты участников в него не входят.

## Поля вопроса

| Поле | Значение |
| --- | --- |
| `id` | Обязательно. Уникальные 1–80 латинских букв, цифр, `_`, `-` |
| `title` | Обязательно. Текст вопроса до 300 символов |
| `type` | Обязательно. Один из типов ниже |
| `description` | Подсказка до 2000 символов, по умолчанию пустая |
| `required` | Обязательность: `true` по умолчанию, либо `false` |
| `options` | Варианты ответа, без повторов. Для текста не нужны; для шкал заполняются автоматически |
| `rows` | Строки матрицы |
| `minChoices` | Минимум для `multiple`, по умолчанию 0 |
| `maxChoices` | Максимум для `multiple`, по умолчанию 3 |
| `exclusive` | Варианты из `options`, выбираемые отдельно от остальных |
| `otherOption` | Вариант из `options`, требующий текстового уточнения; для single, multiple, image |
| `startNewPage` | `false` объединяет с предыдущим вопросом, `true` начинает новую страницу. По умолчанию каждый вопрос на своей странице |
| `showWhen` | Условие показа по ответу на предыдущий вопрос |

Вариантов и строк не более 100, каждый текст до 300 символов. Кроме текста, вопрос требует не менее двух вариантов. Минимум выбора не превышает максимум и число обычных вариантов. Исключающий вариант освобождает от минимума. Необязательный вопрос можно пропустить. Неизвестные поля отклоняются, чтобы опечатки не теряли настройки.

## Типы

| `type` | Формат |
| --- | --- |
| `text` | Свободный текст |
| `single` | Один вариант из `options` |
| `multiple` | Несколько вариантов с минимумом, максимумом и исключениями |
| `matrix` | Одна оценка из `options` для каждой строки `rows` |
| `rating` | Шкала 1–10 |
| `stars` | Звёзды 1–5 |
| `nps` | Шкала 0–10 |
| `ranking` | Расстановка всех вариантов `options` по порядку |
| `image` | Выбор одного варианта; картинки добавляются после импорта в редакторе |

У шкал поле `options` можно опустить. Если оно указано, должно точно соответствовать шкале: строки `"1"`…`"10"`, `"1"`…`"5"` или `"0"`…`"10"` соответственно.

## Условия показа

```json
"showWhen": {
  "questionId": "experience",
  "operator": "equals",
  "value": "Да"
}
```

Условие ссылается только на вопрос выше в файле. Операторы: `equals` — совпадает (для списка — включает вариант), `notEquals` — не совпадает, `contains` — содержит (для текста без учёта регистра), `answered` — заполнен. Поле `value` обязательно; для `answered` используйте пустую строку. Для матрицы дополнительно укажите `row` — точный текст строки. В `value` указывается текст варианта, а не его номер. При отсутствии ответа или скрытом родительском вопросе зависимый вопрос скрыт, включая оператор `notEquals`.

Готовый файл `public/templates/questions-example.json` показывает все девять типов, группировку, условия, матрицу, уточнения и ограничения выбора. Изображения, оформление, стартовая форма, расписание и публикация настраиваются в редакторе.
