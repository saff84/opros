# Расширение сервиса опросов

Порядок согласован 15.10.2026: сначала воронка, источники и QR-коды, проверка публикации и мобильный предпросмотр, автоматические резервные копии. Затем остальные функции из согласованного списка.

- [ ] Воронка и прохождение страниц
- [ ] Ссылки с источниками, кампании и QR-коды
- [ ] Проверка перед публикацией и предпросмотр устройств
- [ ] Автоматические резервные копии и статус
- [ ] Расписание публикации
- [ ] Готовые и пользовательские шаблоны
- [ ] Шкала, звёзды, NPS, ранжирование и выбор изображения
- [ ] Текстовое уточнение варианта «Другое»
- [ ] Сравнение периодов, опросов, отделов и регионов
- [ ] Несколько администраторов и роли
- [ ] Скачиваемый PDF с диаграммами и фильтрами
- [ ] Миграции, тесты, Docker и документация

Существующие опросы, ответы, версии и подписанные сессии должны сохранять совместимость. Новые возможности работают локально, без отправки ответов сторонним сервисам.
