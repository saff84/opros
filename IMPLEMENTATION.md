# Расширение сервиса опросов

Порядок согласован 15.10.2026: сначала воронка, источники и QR-коды, проверка публикации и мобильный предпросмотр, автоматические резервные копии. Затем остальные функции из согласованного списка.

- [x] Воронка и прохождение страниц
- [x] Ссылки с источниками, кампании и QR-коды
- [x] Проверка перед публикацией и предпросмотр устройств
- [x] Автоматические резервные копии и статус
- [x] Расписание публикации
- [x] Готовые и пользовательские шаблоны
- [x] Шкала, звёзды, NPS, ранжирование и выбор изображения
- [x] Текстовое уточнение варианта «Другое»
- [x] Сравнение периодов, опросов, отделов и регионов
- [x] Несколько администраторов и роли
- [x] Скачиваемый PDF с диаграммами и фильтрами
- [x] Миграции, тесты, Docker и документация

Существующие опросы, ответы, версии и подписанные сессии должны сохранять совместимость. Новые возможности работают локально, без отправки ответов сторонним сервисам.
